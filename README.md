# employee-attrition-analysis
Employee Attrition Analysis using Excel, SQL, Python and Machine Learning

## Project Overview
This project analyzes employee attrition using the IBM HR Analytics dataset. The objective is to identify factors affecting employee turnover and build a predictive model using Machine Learning.

## Tools Used
- Microsoft Excel
- SQL
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## Dataset
IBM HR Analytics Employee Attrition Dataset

## Project Activities
- Data Cleaning
- Exploratory Data Analysis
- Pivot Tables and Charts
- SQL Query Analysis
- Machine Learning Model (Random Forest)

## Key Findings
- Overtime contributes to higher attrition.
- Salary impacts employee retention.
- Some departments have higher turnover rates.
- Machine Learning can predict attrition effectively.
